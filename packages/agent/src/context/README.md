# 请求上下文管理

`LLMContextManager::prepare` 从原始会话创建请求草稿，调用方提供本轮的 system、tools、模型配置和取消信号。
它只准备检查点，不改变会话。`commit` 在 `BeforeRequest` / `Request` hook 完成后检查最终请求，确认落盘成功才启用检查点。

## 模块职责

- `manager.rs`：近期消息选择、压缩触发、失败回退和提交。
- `models.rs`：策略、检查点和版本化存储快照。
- `messages.rs`：检查工具调用/结果配对，生成不可拆分的工具往返分组。
- `budget.rs`：统计系统提示、消息（含 reasoning 和工具参数）、工具定义及协议开销。
- `observation.rs`：只裁剪模型可见的工具结果副本，保留原文序号。
- `compactor.rs`：增量生成 Markdown 检查点；旧记录作为数据传入，超大输入分批处理。
- `history.rs`：有 token 上限的历史搜索与原文分页读取。

## 数据与持久化

原始消息只追加，`message_seq` 是原始数组中的一基序号，包括内部日志。先确定序号，再过滤内部消息。
不得重排或删除单条原始记录；未来若支持编辑/分支，需要新增历史版本或显式稳定 ID。

检查点 `{through_seq, summary}` 覆盖 `1..=through_seq`。模型上下文由历史摘要和该序号之后的连续消息组成。
在长用户轮次中切分时，会额外保留当前用户请求原文一次。系统提示词由 `PromptRegistry` 每次独立注入，摘要以 assistant 历史消息呈现。

会话持久化使用独立的可靠队列，广播仅用于通知。`context-v1` 将完整原始消息与检查点写入同一加密快照，采用临时文件、同步和原子替换。
检查点提交等待写入确认；磁盘失败不更新内存检查点。`flush` 等待已接收的写入并报告期间的落盘错误。
普通消息仍异步保存；进程被强制终止时，未完成的尾部写入不保证已落盘。

旧会话没有 `context-v1` 时读取 `real`，忽略无覆盖序号的旧 `compaction`，下一次需要时从原始历史重建摘要。
损坏的原始存储会报告错误，不会被当作空历史覆盖。

## 请求流程

1. 从会话快照读取原始消息和已提交检查点，校验原始工具配对。
2. 大工具结果使用有界预览；原文可通过 `read-history(message_seq, offset)` 读取。
3. 完整请求接近安全预算时，进一步裁剪较旧工具结果。
4. 仍有压力时按 token 选连续近期窗口，优先保留完整用户轮次，至少保留最新完整工具往返。
5. 使用“旧检查点 + 新历史”生成新检查点，摘要请求自身也要满足输入/输出预算。
6. 正常结束、有正文、格式和长度合法、最终请求合法且更小，才允许提交。
7. 摘要失败时，如原请求仍在安全预算内则继续使用原请求；否则明确失败。取消不回退。
8. 仅明确的模型上下文超限、且尚未输出内容时，强制压缩并重试当前模型步骤一次；不重新追加用户输入或执行工具。

`Request` hook 可以修改草稿，但最后必须经过 `commit` 的配对和预算检查。工具调用组之间不能插入未配对结果。

## 默认策略

| 参数 | 默认值 |
| --- | ---: |
| 近期 token 目标 | 16000 |
| 摘要输出上限 | 4096，最多为模型窗口的 1/8 |
| 工具结果预览 | 4096，随小窗口缩小 |
| 较旧工具结果预览 | 1024 |
| 安全余量 | 8192，最多为模型窗口的 1/8 |
| 压缩触发比例 | 安全输入预算的 85% |
| 每次压缩最多摘要批次 | 16 |

模型配置支持可选的 `maxOutputTokens` 和 `inputLimit`；旧配置无需迁移。
输出默认值为 `min(8192, context_size / 4)`，请求中的输出限制与预留一致。
安全输入预算为 `min(context_size - output_limit, input_limit) - safety_buffer`。
近期目标会进一步受固定提示词、输出与摘要预算约束，不会每轮强行截到 16000。

Token 统计采用本地 tokenizer 和安全余量，是估算值；模型/兼容接口的真实计数可能不同。
当前兼容适配器使用 Chat Completions 的 `max_tokens` 输出参数。

## 验证

在 `packages/agent` 目录运行 `cargo test --locked --offline`。
`tests/context_manager.rs` 覆盖配对、失败、长轮次、分批、预算及原文回读。
`tests/context_runtime.rs` 覆盖持久化、旧会话迁移和真实循环的单次超限恢复。
